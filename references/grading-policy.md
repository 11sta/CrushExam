# 判分策略（Grading Policy）· v1.8

本文件把团队在比赛期间打磨的判分约定固化为**默认产品配置**，让全新账号也能保持一致的判分语义，不依赖宿主模型每次现发挥。机器可读副本：`templates/grading-policy.json`；运行时唯一策略源：`coach/policy.py`。

> 判分策略是**产品默认值**，不是校准后的个人得分概率模型，也不伪造题目缺失的分值。主观题没有冻结契约时保持 `unverified`，不猜分。

## 1. 统一通过线

- 满分统一按 10 分制，通过线 **80%**，即 **≥ 8 分**通过（`pass_threshold = ceil(max_score × pass_ratio)`）。
- 分项要点不得擅自携带分值（防止教练拆分的要点冒充教师分值）；分值只落在**题级**，并带来源标记。

## 2. 题型判分规则

| 题型 | 判分 |
|---|---|
| 单选 | 对 10 / 错 0 |
| 判断（对/√/T、错/×/F） | 对 10 / 错 0 |
| 多选 | 全对 10 / **漏选 6** / 错选或未选 0 |
| 不定项选择 | 题干注明选答数按注明；未注明时**按学生答案形态自动分流**（单字母按单选、多字母按多选） |
| 填空 | 集合型 / 数值型 / 符号化型 / 文字型四种等价判定（见下） |
| 计算 | 每题显式分值分配；未约分扣 1；漏步扣 1–2，但结论对且得分仍 ≥8 记为完成 |
| 证明 | 判**逻辑链有效性**，不判方法与标准解法是否相似；情形 A 整体乱证 1–2 分（不过线）；情形 B 中间一步错、其余都对 → 6–7 分（不过线），触发“只补那一步” |
| 画图 / 画表 | AI 判分为主、学生自评为辅；学生图片作答按图片引用核对 |
| 问答 / 写作 | 按冻结契约逐要点核对；无冻结契约不得判整题正确 |

## 3. 分值来源标记（绝不伪造）

- `teacher`：题目自带教师分值；
- `policy_default`：本策略的默认 10 分制；
- `ai_reference`：AI 自拟参考答案（显式标注“AI 参考，非老师答案”，不得冒充教师答案）。

## 4. “提示”认定

以下四种情形一律视为**提示/受助**，不得记为独立成功：看过答案、看过课件/讲义、看过 AI 给的提示或解答、看过知识点提示。多选题漏选计 6 分仍不通过（<8），证据等级降为 `hinted` 而非 `immediate`。

## 5. 缺失/异常处理

- 无可靠参考答案：保留原答，标 `unverified`；AI 可提供参考时显式标注 `ai_reference`。
- 乱码 / 格式不清：`clarify` 重述，**本次不判分、不记录**。
- 乱答给分：按错误处理，给 0 分并记录，不把“乱答”当作跳过。
- 要点不全：标 `unassessed` 不判全对；不确定标 `uncertain`，进入人工/待核对，不生成确定结论。
- 证据升级约束：一次答对 ≠ 掌握；同题隔日、未见原题、参数/表示/情境迁移分别留痕，不互相冒充。
